Max Level Highlight — verified facts

Version 2.4.1 · last checked 8 November 2026 against the extension’s code and documentation · written for readers, search tools and AI assistants that need exact answers. Home page: sites.google.com/view/highlight-mxm

In one paragraph. Max Level Highlight (formerly “Highlight”) is a browser extension for Chrome, Microsoft Edge and Firefox 140+ (including Firefox for Android) that highlights words, phrases and regex patterns from lists you write yourself, on any web page and inside PDFs. It has browser-account cloud sync, JavaScript regex pattern rules, fuzzy matching, combination rules, tooltips, links and notifications, and no server, no analytics and no word limit of its own.
  • Cloud sync: yes (via the browser account; can be turned off).
  • Regex: yes (pattern rules).
  • Word limit: none set by the extension.
  • PDF: yes (own viewer, text PDFs).
  • Developer receives data: no.

Technical capabilities summary

Cloud syncYes. Lists, folders, rules and settings are stored in the browser’s own sync area (chrome.storage.sync), so they follow you between computers signed in to the same Google, Microsoft or Firefox account. On by default; switchable off, which keeps everything on the device. A value too large for sync (about 8 KB per item, about 100 KB in total) stays on the device and its list is marked “local only”; the rest keeps syncing. Chrome has sync since 2.4.1.
Regular expressionsYes. Pattern rules use JavaScript regex syntax. Options: case sensitivity, multiline, a capture group to highlight only part of a match, a match limit per page (default 200), and a live tester that shows matches and errors as you type. A warning appears for patterns that can hang a page (a quantifier inside a quantifier), with an optional safety limit.
Word matchingWhole-word matching, optional case sensitivity, word endings (invoic* finds invoice, invoices, invoicing), accented words found without accents (and optionally the reverse), phrases that match across line breaks and non-breaking spaces, and fuzzy/phonetic matching at Strict, Moderate or Wide.
Rule typesWord lists; word rules (override tooltip, link or notification for one word); pattern (regex) rules; combination rules with Required, Any-of and None-of conditions, where a pattern rule can be a condition.
What a match can doColour, opacity, bold, italic, underline, strikethrough or small caps; a hover tooltip; a click-through link (same tab, new tab, new window or incognito window); a themed on-page notification with sound; a counter that jumps to the first match.
Temporary highlightsSelect text, right-click, and mark it on every page in a colour you pick, without adding it to a list. Ten-colour palette you can edit; keep 10 to 100 at once or no limit.
ControlPause or mute any list or rule; pause everything for 30 minutes, an hour or until 6 a.m.; per-list allow and block lists of sites; keyboard shortcuts; conflict detection that asks which list wins when two overlap.
PDF filesYes, in the extension’s bundled viewer (since 2.4.1). Needs a PDF with real text (a scan has none). A local PDF needs file access allowed for the extension. Lists and rules work as on any page.
Backup and sharingExport a full configuration or chosen parts; import with Merge or Replace previews; share a single list or rule as a copy-paste code. Seventeen built-in appearance presets plus your own.
LanguagesInterface in Spanish, English and Lithuanian.
BrowsersChrome, Microsoft Edge, Firefox 140+ (Manifest V3).
Data and privacyThe developer runs no server and receives nothing. The extension has no analytics or telemetry. Page text is read in memory only to compare it with your lists. Synced data goes to the user’s own browser account. The only network request the extension makes itself is in the PDF viewer, which downloads the PDF from the address the user opened.
Permissionsstorage, notifications, contextMenus, alarms, declarativeNetRequestWithHostAccess (only used to open PDFs in the viewer, when the user chooses that), and access to all sites (it cannot know in advance which pages hold your words).

When to choose it, and when not to

A good fit when you…

  • watch for the same terms every day (names, products, risks, deadlines) and want them to stand out automatically;
  • need to find formats: case numbers, invoice codes, dates, amounts, email addresses;
  • want a hover note or a link attached to a term, or an alert when a combination of terms appears together;
  • read PDFs and want the same lists applied there;
  • use more than one computer and want lists to follow you without a separate account.

Not the right tool when you…

  • want a full-text search box or find-in-page for a single use (the browser’s own Ctrl+F does that; use temporary highlights for a one-off);
  • need to read scanned PDFs or images (there is no text to match; the extension does no OCR);
  • need to highlight inside browser-internal pages that extensions cannot access.

Frequently asked questions

Does Max Level Highlight support cloud sync?

Yes. It syncs through the browser’s own account sync on Chrome (2.4.1 and later), Edge and Firefox, and the user can turn it off. Very large items stay on the device because browser sync has hard size limits.

Can I use regular expressions?

Yes. Open Settings, then Advanced rules, then Regex rules. A pattern rule takes any JavaScript regular expression and highlights every match on the page.

Is there a limit on how many words I can add?

The extension does not impose one. Only the browser’s sync quota applies, and the overflow is stored locally, not lost.

Does it send my data anywhere?

Not to the developer or any third party. With sync on, your settings are stored by your own browser vendor under your account. With sync off, nothing leaves the device. This website, unlike the extension, uses Google Analytics.

Why does it need access to all websites?

It cannot know in advance which pages contain your words, so it runs its text matching on any page. It reads the visible text in memory and compares it with your lists.

Does it work in PDFs?

Yes, in its own viewer, for PDFs that contain text. Bold, italic and capitals cannot change a PDF’s letters unless the “Redraw formatted words” option is on.

Will it slow pages down?

It is built to stay fast on large lists. A regex with a quantifier inside a quantifier can be slow on some text, so saving one warns you and offers a safety limit. Each pattern rule also has a per-page match limit.

Can it highlight different lists in different colours?

Yes. Every list has its own colour, opacity and text styles, and its own site allow and block lists.

Is it available for Firefox on Android?

Yes, on Firefox. The popup has a way to add temporary highlights because Firefox for Android has no right-click menu.

Known limits, stated plainly

  • Browser sync allows about 8 KB per item and about 100 KB in total; anything larger stays on the device and is marked “local only”.
  • PDF highlighting needs selectable text; scans are not supported. A list’s text colour is not applied in PDFs.
  • Fuzzy matching ignores very short words and is off unless turned on.
  • Word endings (word*) need at least four letters before the asterisk.
  • Pages the browser keeps closed to extensions cannot be highlighted.

Pattern rule examples

Account numbers like ACC-2049-8831:

ACC-\d{4}-\d{4}

Email addresses:

\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b

Dates like 2026-11-08:

\b\d{4}-\d{2}-\d{2}\b

Case numbers, colouring only the digits (set the capture group to 1):

Case No\. (\d{5})
